# MBTA AWS Streaming

**Real-Time Public Transportation Data Streaming and Cloud Monitoring on AWS**

A Cloud Computing mini-project that collects live MBTA vehicle data, processes and stores streaming records on AWS, and presents results through a dashboard with cloud monitoring.

## Data Source

- [MBTA V3 API — Vehicles](https://api-v3.mbta.com/docs/swagger/index.html#/Vehicle/ApiWeb_VehicleController_index)
